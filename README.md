# Nome do Projeto

Site desenvolvido para apresentar as ilustrações de Aksel Jacques.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Galeria de obras
- Página individual para cada ilustração
- Layout responsivo para celular
- Animações e transições suaves

## Como executar

Basta abrir o arquivo `site.html` ou acessar a versão publicada no GitHub Pages.
